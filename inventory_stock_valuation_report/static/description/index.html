Stock Valuation Report for Odoo 19

A detailed inventory valuation view for analyzing incoming and outgoing inventory transactions with moved quantity, unit value, total value, product and transaction reference.

Overview

Stock Valuation Report provides a clear list-based view of inventory valuation transactions in Odoo 19. It is designed to reconstruct the practical valuation-analysis experience of the Odoo 18 view in an Odoo 19-compatible interface.

Review inventory movements together with their valuation information and quickly analyze the financial value associated with stock transactions.

Incoming & Outgoing

Review valuation information for inventory transactions moving into or out of stock.

Transaction-Level Detail

See the transaction reference, product, transaction date, moved quantity, unit cost and total value.

Odoo 19 List View

Use a familiar Odoo list view with filtering, grouping and standard export capabilities.

Valuation List Fields

Field Purpose
Transaction Reference Identifies the inventory transaction or related stock reference.
Product Shows the product associated with the valuation transaction.
Transaction Date Shows when the inventory transaction occurred.
Moved Quantity Shows the quantity moved by the transaction.
Unit Cost / Unit Value Shows the value assigned per unit.
Total Value Shows the total valuation amount for the transaction.

Odoo 18 View Reconstruction for Odoo 19

This module brings the valuation-analysis view concept into an Odoo 19 interface, with a dedicated list presentation focused on transaction reference, product, date, quantity, unit value and total value.

Where to Find the Report

Report menu path: Inventory  ›  Reporting  ›  Valuation History

Open Inventory, go to Reporting, and select Valuation History to access the stock valuation transaction report.
